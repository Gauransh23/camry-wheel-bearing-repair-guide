# Source register

This register mirrors the linked evidence in the guide and summarizes the claim each source is used to support. Research notes were compiled October 7–8, 2026. Reprinted Toyota material hosted on third-party sites is not an official Toyota publication. Link availability and current vehicle applicability must be checked directly. Use Toyota TIS with the actual vehicle build for final application-specific instructions.

## S1: 2011 2.5L front drive shaft installation — Toyota procedure reprint

- Evidence class: Factory text · exact year/engine · TMC branch
- Source: [2011 2.5L front drive shaft installation — Toyota procedure reprint](https://charm.li/Toyota/2011/Camry%20L4-2.5L%20%282AR-FE%29/Repair%20and%20Diagnosis/Transmission%20and%20Drivetrain/Drive%20Axles%2C%20Bearings%20and%20Joints/Axle%20Shaft%20Assembly/Service%20and%20Repair/Removal%20and%20Replacement/Front%20Drive%20Shaft%20Assembly%20%28for%20TMC%20Made%29/Installation/)
- Used for: Axle nut 294 N·m; flange fasteners 75 N·m; tie rod 49 N·m; sensor 8 N·m; hose/wire bracket 19 N·m; new axle nut, staking, new tie-rod cotter pin. Indexed text was readable; direct mirror retrieval was intermittent. TMMK-specific axle internals are outside this guide. Exterior-joint equivalence for the TMMK branch was not independently established; match the actual build in Toyota TIS.
